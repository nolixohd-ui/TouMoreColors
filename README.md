## Installation

1. Install the mod using the same setup process as Town Of Us Mira.
2. Once Town Of Us Mira is installed, place `MoreColors.dll` into the `[MODFOLDER]/BepInEx/plugins/` folder.
3. Launch Among Us. All MoreColors Color will appear **under the TouM Colors** in the color menu of the inventory.

For the simplest install, make sure your Town Of Us Mira installation is working first, then add `MoreColors.dll` to the plugins folder.
